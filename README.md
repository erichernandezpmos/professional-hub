# Eric Hernández – Professional Hub

MVP HOME de portafolio profesional.

**Stack:** Next.js 16 (App Router) · TypeScript · Tailwind CSS v4

**Hosting objetivo:** Vercel (Hobby – gratis)

## Quick start

```bash
npm install
npm run dev
```

## Contenido actual

- HOME completa con foto profesional
- Estilo dark (purple/pink) inspirado en referencia visual
- Secciones: Hero, About + métricas, Featured Projects, Contact
- Placeholders listos para reemplazar
